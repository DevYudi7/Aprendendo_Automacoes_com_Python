# Exercícios com Pathlib

Pasta com exercícios para praticar o uso da biblioteca `pathlib` em Python.

## Conteúdos

* Criação de diretórios
* Criação de arquivos
* Manipulação de caminhos
* Verificação de arquivos e diretórios
* Organização de pastas
* Uso do `Path`
* Uso de `mkdir()`
* Uso de `exists()`

## Objetivo

Praticar o gerenciamento de arquivos e diretórios em Python como parte dos estudos de automação.

## Tecnologias

* Python
* Pathlib
