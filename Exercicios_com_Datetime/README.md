# Exercícios com Datetime em Python

Pasta criada para armazenar meus exercícios e práticas com o módulo `datetime` em Python.

## Sobre o projeto

Durante meus estudos de Python, estou aprendendo a trabalhar com datas, horários e intervalos de tempo, utilizando o módulo `datetime`.

Este repositório reúne exercícios desenvolvidos para praticar esses conceitos e melhorar minha lógica de programação.

## Conteúdos estudados

* Importação do módulo `datetime`
* Data e hora atual com `datetime.now()`
* Criação de datas com `datetime()`
* Formatação de datas com `strftime()`
* Conversão de strings para datas com `strptime()`
* Operações com datas e horários
* Diferença entre datas com `timedelta`
* Cálculo de prazos e vencimentos
* Cálculo de dias restantes para eventos
* Práticas de automação utilizando datas
